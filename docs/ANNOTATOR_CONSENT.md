# Consentement annotateurs / validateurs (issue #16)

Modèle de consentement pour validateurs externes (#5) et traducteurs (#14).

## Informations fournies au contributeur

- Objectif : améliorer la qualité du benchmark AfriBench (QCM et traductions)
- Durée estimée : batches de 30–50 items (~2–4 h)
- Rémunération : selon accord individuel (voir `docs/VALIDATORS.md`)
- Données traitées : questions, options, explications (pas de données personnelles des contributeurs dans le corpus public)

## Consentement

En participant, je consens à :

1. Réviser les items qui m sont assignés selon `docs/VALIDATION_PROTOCOL.md`
2. Autoriser l utilisation anonymisée de mes corrections dans le dataset public
3. Ne pas partager publiquement les batches avant publication officielle

## Retrait

Je peux retirer ma contribution avant la release v1.0 en contactant l équipe AfriBench.
